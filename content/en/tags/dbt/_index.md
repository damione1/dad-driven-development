dbt is the link between the transformation code and the decisions a data team has to maintain: how models are tested, what columns mean, and which rules are enforced before deployment.

Start with [treating transformations as infrastructure]({{< ref "/blog/dbt-data-infrastructure-as-code/" >}}), then [documentation and governance]({{< ref "/blog/dbt-documentation-governance-yml/" >}}). For an example of the tooling around those checks, see [dbt-guard]({{< ref "/blog/dbt-guard-package-python/" >}}). The posts below describe the choices, limits and implementation details.
