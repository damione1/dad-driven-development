dbt relie le code des transformations aux décisions qu’une équipe data doit maintenir : comment tester les modèles, ce que signifient les colonnes et quelles règles vérifier avant le déploiement.

Commence par [les transformations comme infrastructure]({{< ref "/blog/dbt-data-infrastructure-as-code/" >}}), puis [la documentation et la gouvernance]({{< ref "/blog/dbt-documentation-gouvernance-yml/" >}}). Pour un exemple d’outil autour de ces vérifications, voir [dbt-guard]({{< ref "/blog/dbt-guard-package-python/" >}}). Les articles ci-dessous décrivent les choix, les limites et les détails d’implémentation.
